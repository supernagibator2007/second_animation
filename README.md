## Описание проекта
Программа визуализирует слово в виде динамических частиц и симулирует физику поведения точек (отталкивание от курсора мыши)

## Функциональные возможности

### Основной функционал
Интерактивное управление частицами с помощью курсора мыши  
Симуляция физики поведения точек

### Дополнительный функционал
Добавление своего слова через .txt файла  
Автоматическое создание слова 'train' в случае отсутствия шаблона

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** tkinter, math, os, random (все встроенные)

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/supernagibator2007/second_animation
cd second_animation
```

### 2. При желании можно создать виртуальное окружение, однако программа будет работать и без него, т.к. не используются сторонние библиотеки
Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```
### 3. Запуск программы
```bash
python main.py
```
